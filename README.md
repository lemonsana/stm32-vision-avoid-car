# 循迹小车 · 视觉避障（K210 + STM32F103）

STM32 循迹小车加一路 K210 视觉：K210 跑 YOLO 检测障碍物，通过 USART 把检测框发给 STM32，STM32 在模式 5 里判断"够近了没有"，够近就停车、向外转、绕过障碍、再找回黑线继续循迹。

本仓库是这套避障功能的完整工程：STM32 源码（Keil MDK）、K210 脚本、单测、以及踩坑记录和调参文档。

## 这一版改了什么

**避障开始时和回线都太早了**——旧触发条件只有"类别对 + 框落在前方通道内"，障碍物还在 30~40cm 外一进画面就开始绕；而绕过、越障、回线整段都是从触发那一刻按时间推进的，所以触发提前 30cm，回线也就跟着提前 30cm，绕到一半就切回原线。

现在改成**按距离触发**：用检测框底边 `yb = y + h`（= 障碍物接地点在图像里的行号）反算摄像头到障碍物的距离，估算距离 ≤ `VA_TRIGGER_CM`（默认 **10cm**）才开始绕行。

- 单目一帧本来测不了距，但障碍物立在赛道上，框底边就是接地点：车越近行号越靠下，且与障碍物本身多大多高**无关**。
- 距离模型让 `1/d` 对 `yb` 线性，两点标定（10cm、20cm 各量一次行号）；代码里放大 10000 倍做整数运算，不引入浮点库。
- 加 60ms 时延补偿：曝光 80ms + K210 卡尔曼滞后 + 串口 50ms 这段时间车又走掉 6~10cm，按最近两帧底边行号的变化率外推一句再判。
- 没动动作时序（`VA_TURN_OUT_MS`/`VA_SHIFT_MS`/`VA_STRAIGHTEN_MS`/`VA_PASS_MS`/`VA_TURN_IN_MS`），没动串口协议，也没动 K210 脚本——串口协议和 SD 卡里的东西都不用重新弄。

⚠️ 上板前必做两件事：**标定两个行号**、**用 Keil 重新编译烧录**。详见 `小车源码/ZYSTM32-A0-main/docs/视觉避障-模式5使用说明.md` 的"距离门限：10cm 才绕行"一节。

## 快速上手

1. **K210**：把 `K210配套/main.py`、`det.kmodel` 放到 SD 卡（`/sd/KPU/train_model_and_use/det.kmodel`），上电前先把车摆在赛道上让自动曝光收敛（脚本里冻结了曝光）。
2. **STM32**：Keil 打开 `小车源码/ZYSTM32-A0-main/USER/Template.uvprojx`，F7 编译，烧录 `OBJ/vision.hex`。
3. **接线**：K210 TX/RX → STM32 USART2（PA2/PA3），115200 8N1，共地。
4. **跑**：上电默认进模式 5（T5 视觉循迹避障），串口每秒打印一行 `[vision]` 便于观察。
5. **跑测试**（可选，不需要硬件）：`python tests/test_vision.py`，可用环境变量 `GCC` 指定编译器。

## 调参速查

| 现象 | 改什么 |
| --- | --- |
| 车快贴上了才动 | `VA_TRIGGER_CM` 12~14，或 `VA_PREDICT_MS` 100 |
| 还差很远就动 | 检查 `VA_ROW_AT_10CM` / `VA_ROW_AT_20CM` 标定（`ROW20` 必须小于 `ROW10`） |
| 10cm 处检测掉 0 | `VA_TRIGGER_CM` 加到 12~14，或 K210 YOLO 阈值 0.3→0.25 |
| 反应还嫌慢 | `VA_CONFIRM_HITS` 改 1（单帧触发，误检也会绕） |
| 回线偏早/偏晚 | 加/减 `VA_PASS_MS` |
| 退回旧行为 | `VA_TRIGGER_CM` 改 `0`，不用改代码 |

调试行：`[vision] st=… fault=… link=… found=… x=… yb=… d=…cm tr=… confirm=… left=… rx=… ok=… bad=…`
标定时就看 `yb`（框底边行号）和 `d`（估算距离），`tr` 是当前 10cm 对应行号。

## 串口协议

29 字节定长：`$ len=27 cmd=0x12 0xBB data_len=22 ,数据… checksum #`，数据段为 `x,y,w,h`（小端 u16）+ `id` + `confidence` + `found`。无目标时每 50ms 也发心跳帧。详细格式见 `K210串口通讯协议.xlsx` 与 `SYSTEM/vision/vision_link.c`。

## 已知限制

- 单目测距假设障碍物立在赛道上，离地/悬空目标不适用；30cm 内误差约 ±3~5cm。
- `yb` 在很近时被画面底边钳在 239，默认几何下约等于 8cm，再近就读不出来（正好当"极近"用）。
- 绕行是定时的，不建图、不检测车尾是否已过障碍，靠 `VA_PASS_MS` 实测保证；不处理绕行中出现的第二个障碍。
- 编译产物不入库；本机 `OBJ/vision.hex` 仍是**改动前**的旧固件（本机没装 ARMCC 未能重编），要新固件请用 Keil 编译。
